08. AI Shopping: Universal Cart · UCP · AP2

(Demo screenshots from the keynote: Three smartphone cart screens. The first shows a compatibility warning, "Before you checkout… The CPU and motherboard in your cart are not compatible. The Ryzen 7 CPU requires a motherboard with an AM5 socket," with a "Get recommendations" button. The second shows "5% off at Target with your Target Circle Card" plus items from Target. The third shows a unified cart with a prominent "Buy now" button bridging Target and Ulta Beauty items in a single checkout.)

So when I shop, the AI assistant actually buys things for me?

UCP (Universal Commerce Protocol)

  • An open-source common language for AI shopping agreed on by Google, Amazon, Meta, Microsoft, Salesforce, and Stripe
  • Any agent can read product catalogs and process payments in a consistent format

Universal Cart

  • A unified shopping cart that spans every Google service: Search, Gemini, YouTube, Gmail
  • Monitors price history, coupons, and restocks in the background
  • For PC builds, it checks CPU/motherboard socket compatibility
  • Built on Google Wallet, so it automatically compares which credit card gets you the best benefits
  • Integrates with services like DoorDash and Instacart

AP2 (Agent Payments Protocol)

  • A safety layer for anyone nervous about handing their wallet over to an AI assistant
  • The AI can only make autonomous purchases within the brands, products, and budgets you've set
  • Payment authorization and transaction records are kept transparent and auditable

Antigravity 2.0 update guide

A troubleshooting guide for users caught off guard by the 2.0 update, where the old structure and the extension system are gone. Pick one of the two paths based on whether you want to adapt to the new IDE or roll back to the old version.

(Click the toggle arrow to open)

▼ Method 1. Move to the new "IDE version" and recover your extensions

Adapt to the new 2.0 structure (IDE) while bringing your existing extension data along.

Step 1: Uninstall existing programs and resolve conflicts

  1. Uninstall both Antigravity 2.0 and your previous version from your computer.
  2. If you hit errors during uninstall or reinstall, open Task Manager (Ctrl + Shift + Esc).
  3. Type anti in the search bar, find every related process, and force-quit them all with "End task."

Step 2: Install Antigravity IDE

  1. From the Antigravity official site, go to the top menu and download Product → antigravity IDE.
  2. Run the downloaded file, complete the installation, then close (quit) the program for now.

Step 3: Restore your extension data

  1. Open File Explorer, go to the path below, and copy everything inside it.
    Path: C:\Users\YourComputerName\.antigravity\extensions
  2. Navigate into the newly created folder at the path below and paste the copied contents there.
    Path: C:\Users\YourComputerName\.antigravity-ide\extensions
  3. If you see an extensions.json file in the folder you just pasted into, delete only that file.
  4. Now relaunch "Antigravity-IDE" and your existing extensions will be restored properly.
▼ Method 2. Block the update and roll back to the "old version"

Skip the new structure entirely. Force-block updates and keep using the old version as-is.

Step 1: Uninstall the program

  1. Go to Windows Settings → Apps → Installed apps and completely remove the currently installed Antigravity files.

Step 2: Reinstall the old version

  1. Search your computer for the old installer file Antigravity.exe that you downloaded previously, and run it. (If you don't have the file, you'll need to source the old version installer again before continuing.)

Step 3: Force-cancel the update (most important ⚠️)

  1. During install and launch, a white pop-up will appear: "Antigravity is running. Click OK to close it."
  2. At this point, you must click Cancel.
  3. If you click "OK," it will automatically update to 2.0, so be careful. (If you clicked OK, you'll need to uninstall and reinstall again.)
  4. This pop-up will appear every time you reopen the program, so to keep the old version, you'll need to hit Cancel every single time.

🔒 Infrastructure & Trust: TPU 8 Series · SynthID

TPU 8 series

  • This year's infrastructure spend: $180 to $190 billion
  • TPU 8t (training): 3× the compute capacity of the previous generation. Distributed training across over 1 million TPUs worldwide via JAX + Pathways
  • TPU 8i (inference): 1,500 tokens per second inference speed. Fast enough that agent responses feel instantaneous

SynthID + C2PA

  • The watermarking standard for verifying whether content was AI-generated

  • In Chrome, you can right-click an image to check whether it was captured by a camera or AI-edited
  • Partners now include OpenAI, NVIDIA, Kakao, ElevenLabs, and more

Key Insights: What this announcement actually means

1. "Chatbot → Agent" isn't marketing speak anymore

The moment Google embedded Spark, search agents, and shopping agents into real products, agents stopped being a concept and became a product. This is happening inside an ecosystem of 3+ billion users, so the ripple effects hit different.

2. The cost barrier has collapsed

With 3.5 Flash priced at ~$0.10 per task, running an agent 24/7 is now within reach for individuals. The Antigravity OS demo coming in under $1,000 says the same thing. We're moving from calculating the cost of using AI to calculating the cost of not using it.

3. The definition of search has changed

The search that used to return 10 links is now writing widgets, generating dashboards, and managing shopping carts. The structure has shifted: search itself is the destination, not the website. Content SEO strategy may need to be rethought from the ground up.

4. A common language for shopping is a massive signal

Google, Amazon, Meta, and Microsoft agreeing on UCP means AI agent commerce is no longer an experiment. It's at the infrastructure stage. If you run an e-commerce business, start preparing for UCP now.

5. Hardware is preparing for "what comes after the phone"

Audio glasses launching in partnership with fashion brands like Gentle Monster and Warby Parker is a deliberate move to position this as an everyday accessory, not a tech gadget. A head-to-head against Meta Ray-Ban.

6. Omni is the game-changer for video AI

The point isn't simple generation. It's a world model that understands physics. While other video AIs make "pretty videos," Omni makes "videos that behave like reality." The competitive landscape against Sora, Kling, and others just shifted entirely.
